# KG-FedMARL

Research repository for the CPS resilient-recovery manuscript.

## Governing research line

> 在恢复所依据的知识本身可能缺失、过时、相互冲突或被攻击者污染时，如何建立一个有界可信的在线知识状态，并限制错误知识向恢复约束和恢复策略传播。

Subsequent manuscript revisions should treat this as the default research line. Federated learning, heterogeneous agents, shared encoders, personalized adapters, trust aggregation, GAT, and related modules are supporting/inherited infrastructure rather than the primary novelty.

## Repository layout

- `manuscript/`: LaTeX manuscript source and figures.
- `docs/`: review/audit notes and revision guidance.
- `references/`: reference manifest for prior and external papers used during revision.

Generated build products and temporary render files are intentionally excluded from version control.
